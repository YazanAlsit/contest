How to read the constraints

A computer does roughly 108 simple operations per second. Look at the largest value of n in the Input section and pick an approach that fits inside the time limit.

Largest nSlowest approach that still fits in 1 s
n ≤ 10 O(n!) — try every ordering
n ≤ 20 O(2n) — try every subset
n ≤ 500 O(n3) — three nested loops
n ≤ 5000 O(n2) — two nested loops
n ≤ 2·105 O(n log n) — sorting, binary search, set, map
n ≤ 107 O(n) — a single pass

A program that prints the right answer but runs past the time limit is rejected as Too slow. Read from standard input, write to standard output, C++ only.
